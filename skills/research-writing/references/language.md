# 语言、句子与段落修改

用于中英文学术段落润色、去 AI 套话、语法纠错与精简。始终先保持技术含义、论断强度与术语指代，再改善语言表达。个案改写不是可批量机械替换的词典。

## 先检查含义，再修改措辞

1. **梳理句段角色**：通读目标句的前后文，确认主语、核心动作、作用对象、前提条件和证据。先概括段落单一主旨，再判断每句话承担定义、解释、证据还是过渡功能。
2. **区分含义硬伤与风格选择**：因果倒置、未定义符号、比较对象不对等、把推测或计划写成既成结论属于含义问题，须实质修正；句长、主动/被动语态和同义词选择通常属于风格调整。
3. **交付与说明边界**：直接返回可替换的定稿文本。仅对调整了论证顺序、删减关键信息、收窄结论强度或需作者补充证据之处简要说明原因。

**硬底线**：润色必须保留原有的实验条件、限定语、数值、否定范围、比较基准及计划/完成状态。`may`、`suggest`、`estimate`、`consistent with` 等词的去留取决于证据强度，不得以“让语气更自信有力”为由删去合理限定；相关性不能直接改写成因果。

## 段落衔接与句子组织

- **围绕单一中心推进**：一段话聚焦一个核心论点，尽早给出主题句（Topic Sentence），再按“机制解释 → 实验/文献证据 → 结论含义”展开。段尾仅在跨段转折或收束复杂推导时按需归结，避免每段机械附加总结句。
- **已知 → 新知信息流（Given–New Principle）**：句首放置读者已知的上下文或上句引出的概念，句尾放置本句新引入的技术机制或重点结论（End-Focus）。优先靠核心概念的前后接力实现自然连贯，避免连续多句机械堆砌 `Furthermore,`、`Moreover,`、`Additionally,`。
- **逻辑连接词匹配实际关系**：先确认两句间的真实逻辑，再选用连接词。`Therefore` / `Consequently` 须有充分因果依据；`In contrast` / `Whereas` 用于同一维度下的明确对比；`In addition` 仅补充并列信息，不能填补推理跳跃。
- **主谓紧凑与动词驱动**：一句话围绕一个主断言展开，从句用于补充条件或局部证据；长句若承载多个独立论点或指代缠绕则主动拆分，但不设死板的字数上限。让主语与核心动词靠近，优先使用直接动词（如用 `We evaluate X` 代替 `We conduct an evaluation of X`），并确认主语在语义上能执行该动作。
- **语态与人称**：主动语态便于指明方法责任与设计动作；当被处理对象或客观流程更重要时保留被动语态。沿用现有稿件与目标刊物的人称约定，`we` 与模型/算法/模块作主语均可按语义自然切换。
- **精准精简与术语一致**：删去无信息增量的开场寒暄、主观自夸和同义重复。**严守术语一致性**：核心概念、模块、变量和任务名称在全文保持唯一固定称呼，切勿为了“避免用词重复”而给同一技术概念换用近义词。

## 去除 AI 套话与浮夸修辞（De-AI-ification）

- **剔除高频空洞修饰**：避免在起草或润色时注入缺乏信息含量的套话与夸张词：
  - 英文慎用无实质指向的修饰词与套语：`delve into`、`pivotal`、`paramount`、`testament to`、`tapestry`、`seamless`、`groundbreaking`、`revolutionary`、`meticulously`、`undeniably`，以及在单节内高频重复 `It is worth noting that` / `Notably`。
  - 中文删去空泛背景套话与口号式自评：如“近年来，随着深度学习技术的飞速发展”“众所周知”“不言而喻”“极大地提升了”“完美解决了……难题”。
- **用具体机制替代主观形容**：不空喊“该方法极其高效且高度鲁棒”，改为陈述具体机制或可观测结果（如“通过稀疏注意力将复杂度从 $O(N^2)$ 降至 $O(N)$”“在 20% 标签噪声下准确率降幅小于 1.5%”）。

## 中文学术写作专项规范

- **补全被介词淹没的主语**：警惕“针对……问题，通过引入……模块，使得/实现了……”这类高频主语残缺句。明确主语归属，改写为“针对……问题，本文提出……方法，通过……模块降低……”或“该模块通过……机制抑制……”。
- **压缩欧化虚动词与名词化冗余**：将“对该模块的有效性进行验证”“实现了对特征表达能力的增强”精简为“验证该模块是否有效”“增强特征表达能力”；保留有助于界定修饰层级的“的”，不作机械全删。
- **转换实验室口语与黑话**：将“涨点/掉点”“刷榜”“跑不过”“训崩了”“加个 trick”转换为规范学术表述，如“指标提升/性能下降”“基准评测对比”“低于基线方法”“训练发散”“引入启发式设计/训练策略”。
- **中英术语与混排规范**：正式中文论文或学位论文中，专业缩写首次出现时采用“中文全称（English Full Name, 缩写）”。除领域公认专有名词（如 `Transformer`、`ResNet`、`LoRA`）外，正文叙述避免直接夹杂 `baseline`、`backbone`、`ground truth`、`trade-off` 等已有规范译法（基线方法、骨干网络、真实标注、权衡）的英文词。

## 按句子的功能选择时态

| 内容类型 | 常用表达 | 判定依据 |
|---|---|---|
| 方法定义、数学性质、算法操作、本文贡献陈述 | `The encoder maps…`; `We propose…` | 描述当前文中的方法机制或持续成立的客观关系 |
| 已执行的训练、采样、测量与对比过程 | `We trained…`; `We observed…` | 明确归属于过去已完成的具体实验动作 |
| 图表展示与文内结构指引 | `Table 2 reports…`; `Section 3 details…` | 描述当前稿件向读者呈现的内容 |
| 单项已发表文献的具体工作 | `Lee et al. proposed…` / `Lee et al. introduce…` | 按叙述视角选择过去时或现在时，同类综述保持一致 |
| 延续至今的研究趋势或累计进展 | `Recent studies have explored…` | 强调从过去延续至当前的演进脉络 |
| 拟开展或开题阶段的工作 | `We plan to evaluate…`; `We will investigate…` | 保留计划状态，绝不伪装成已完成实验 |

同一段落中“方法定义用一般现在时、特定实验过程用一般过去时”完全合理。“时态一致”是指**叙述功能与时间逻辑一致**，而非全文强行统一为单一时态。注意语法术语准确：`have proposed` 是现在完成时，切勿误称为过去完成时。

## 有针对性的语言与语法检查

- **冠词、单复数与主谓一致**：根据名词可数性、特指/泛指语境、数量修饰和上下文判断冠词；缩写词的单复数与展开形式保持一致。不要把“首次出现一律用 a/an”或“所有单数名词必须带冠词”当作机械替换规则。
- **指代清晰与从句标点**：代词 `it`、`this`、`they`、`which` 必须有唯一明确的先行词；若前句含多个名词或整句含义，改用 `this distribution`、`this bottleneck` 等“指示词+概括名词”短语明确指代。按限制性/非限制性定语从句语义及目标英语规范（美式/英式）使用关系代词与逗号，不套用含糊的标点口诀。
- **并列结构与比较对等**：列表项与并列连词（`both…and…`、`not only…but also…`）两侧保持语法结构平行；比较级必须保证比较对象同类对等（模型对模型、指标对指标、复杂度对复杂度，必要时用 `that of` / `those of` 补全）；使用 `respectively` 时确保前后两组序列元素严格一一对应。
- **词义准确优于机械避讳**：优先使用简洁准确的词（如 `use`、`before`、`after`、`because`）。对 `utilize`、`due to`、`prior to`、`following` 等词不设全局禁令，依据具体语境与搭配自然选用，不作盲目批量替换。
- **实验与统计措辞**：区分客观数值观察与机理推测。`significant` / `significantly` 若用于表达统计显著性，须有对应的假设检验或置信区间支持；仅描述数值幅度较大时，改用 `substantial`、`marked` 或直接给出具体提升幅度。
- **缩写管理**：摘要、正文、需独立阅读的图表标题在各自首次需要时定义缩写；仅为文中高频复现的核心概念引入缩写，避免为只出现一两次的普通词组造缩写增加阅读负担。

## 改写示例

以下均为自拟教学演示，不得作为用户论文的实验事实。

| 问题类型 | 原句 | 改写示例与适用边界 |
|---|---|---|
| 名词化与弱动词赘语 | `We conduct an evaluation of the retrieval module.` | `We evaluate the retrieval module.` 中文：评估检索模块。 |
| 把实验现象夸大为认知机制 | `The ablation proves that the module understands the question.` | `Removing the module reduced accuracy in this ablation.` 中文：移除该模块后，本次消融实验的准确率下降。（仅在确有该消融结果时使用；准确率变化本身不直接证明“理解”机制。） |
| 未指明统计估计对象 | `The performance is noisy.` | `The performance estimate varies across runs.` 中文：性能估计值在多次运行间存在波动。（仅在材料确有多次运行记录时使用；否则标出证据缺口。） |
| 计划工作冒充已完成结果 | `Our method outperforms the baselines.`（尚无实验） | `We will compare the method with the baselines under the same evaluation protocol.` 中文：计划在相同评测协议下比较本文方法与基线方法。 |
| 指代不明与机制缺失 | `We add a filter to the encoder, which improves it.` | 先核实过滤对象、`it` 的具体指代（编码器表征还是下游指标）及是否有实验依据，再重写句子；不得仅凭语法猜测补造机制或提升效果。 |
| 中文介词淹没主语与套话 | `近年来随着AI发展，针对噪声问题，通过双分支设计，极大地实现了鲁棒性的提升。` | `针对标签噪声问题，本文提出双分支协同训练框架，在噪声数据上降低了分类错误率。`（须有对应实验支持。） |

## 完成检查

改写后的段落主旨明确；句间依靠概念衔接自然推进；核心术语与数学符号零漂移；限定条件、统计范围与证据强度完整保留；无空洞 AI 套话与悬空代词；新增的因果解释或对比结论均有材料支撑。若修改对象为 LaTeX 源码，须同步保留引用键、标签、宏定义与数学公式语义，详见 [latex-figures.md](latex-figures.md)。
